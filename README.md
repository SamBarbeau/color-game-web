# color-game

Pick the odd color out before the timer runs out. The grid grows, color differences shrink, the clock tightens. High score persists in localStorage.

Live at **[sambarbeau.com/color](https://sambarbeau.com/color)**.

Web reimagining of [an earlier Python/pyglet version](https://github.com/SamBarbeau/color-game-py).
